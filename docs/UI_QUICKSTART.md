# 纯UI改版使用与真机回归

本版以用户已验证的固定机身1.2.0（8）为唯一功能基线。没有加入移动机身补偿，也没有混入独立稳定性分支的行为修改。跟随数学、协议、图传、录像、阈值、后台处理与用户配置全部冻结。

## 安装与使用

1. 使用原Sideloadly账户与原签名身份安装本版新IPA，bundle ID仍为org.headlink.personal；不要先删除旧App，以保留现有设置。新版本号1.2.2，实际构建号与IPA核验记录一起提供。
2. 在“设备”页按原流程连接AirPods与相机。需要手动加入Wi-Fi时，密码仍可显示、复制；加入后返回App点验证。连接成功仍自动进入监看。
3. 主画面底部直接“校准 → 开始／恢复跟随”；录像是另一独立按钮。暂停可直接点击，恢复仍保留原确认；不自动开拍或恢复运动。
4. 顶部相机／耳机状态进入设备页；“…”进入更多。控制轴、响应和安装方式在更多首屏，画面选项与日志在同名二级页。“跟随状态与诊断”按旧行为先暂停；“实时数值与图传”只展示原数值及原手动图传恢复入口。

## 最短真机回归（至少连续5分钟）

使用原来已验证的固定支架、Follow模式和运动范围，不增加新测试角度。

- 确认原保存的控制轴、响应、十字线、左手布局、常亮、震动与诊断开关仍保持原值。
- 连接→一次校准→开始跟随；重复原固定机身左右／上下、保持与回基准动作。记录是否仍符合原1∶1，不把本次UI检查写成新精度测量。
- 跟随与录像运行期间开关“更多”、画面设置、实时数值、本地诊断和设备页，确认原连接、预览、控制持续，面板关闭不自动校准/重连/发运动命令。**同名“跟随状态与诊断”入口仍有原主动暂停语义**，应区别于普通只读数值页。
- 检查录像按钮的待确认、真实REC秒数与停止反馈；仍以相机实际响应为准。
- 横竖屏切换，主要按钮可达、画面不裁切/拉伸；检查大字体、减少透明度、减少动态效果，以及实际亮/暗/细节复杂画面下的可读性。
- 暂停、断连、后台与回前台按旧规则；不自动恢复跟随。保持常亮的键值与原行为不改。原后台主动断连和图传共享恢复策略仍属于第8版行为，不在纯UI分支顺手修复。

不能在无硬件的模拟器中验证连接稳定性、真实图传、校准成功、相机角度、录像响应或跟随时开关面板。云端导航截图明确是未连接的实际App运行，不展示假设备、假视频、模拟校准成功或假录制。

## 未满足的旧项目独立保留

移动机身即断连的真实触发原因与挂脖补偿仍在原研究分支和草稿PR中。本版未改变相机模式或加入补偿，不扩大已验证能力。UI回归结果由用户真机提供；编译、测试和截图不能代替这项验收。
