## 界面与功能冻结

真实画面保持原比例，校准、跟随与独立录像保留为直接按钮；顶部状态进入设备详情，“更多”按任务整理原有设置、完整数值和诊断。原“跟随状态与诊断”入口仍主动暂停，界面明确标注；普通数值页与面板导航不增加业务动作。

iOS 26 使用系统 glassEffect，iOS 17–25 回退系统材质；减少透明度使用实体背景，减少动态效果使用稳定材质。大字体横屏将主要操作排到侧边，状态区使用实体底板避免预览文字干扰阅读。没有新增主题、快捷模式、服务或第三方 UI 库。

沿用同一 AppModel 和原服务，稳定保留视频容器。冻结核验确认 302 个受保护原文件逐字相同，包含控制、连接、视频、耳机、原测试、依赖与资源；视频适配器、状态映射、数值格式、保存键及首次默认一致。生产目标仅改版本号，原设备构建步骤保持不变。

没有更改跟随数学、增益、轴向、坐标参考、限位、超时、命令频率、校准、图传、录像、权限或后台行为；不清空或迁移用户配置。完整入口与参数对应见 [UI_FUNCTION_MAP.md](UI_FUNCTION_MAP.md)。模拟器配置测试的值不代表当前 iPhone 保存值，原手机配置仍需覆盖安装后确认。

## 安装与最短真机回归

使用原 Sideloadly 账户覆盖安装新 IPA，保持原固定支架与已验证运动范围，按“连接 → 校准 → 开始”。至少连续运行 5 分钟，检查左右／上下 1∶1、保持和回基准、真实图传与录像启停；跟随和录像期间开关普通设备／设置／数值面板，再检查横竖屏及系统辅助外观。原“跟随状态与诊断”会主动暂停，恢复遵守原确认。

详细步骤见 [UI_QUICKSTART.md](UI_QUICKSTART.md)。连接成功、校准成功、真实预览／录像、运行中面板切换、亮暗复杂画面可读性、iOS 17–25 回退外观和实际性能均待真机验证。未测量延迟、漂移或性能精度，不作零延迟或性能完全相同的承诺。
