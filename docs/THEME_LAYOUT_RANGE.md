## 实际触发链核查

| 情况 | 第20包路径 | 本轮行为 |
| --- | --- | --- |
| 仅原始目标越过范围 | TrackingController.tick先clamp，再过原有平滑/开始过渡，再clamp命令 | 保留该算法与倍率，连接、有效校准、录像与跟随保留；回到范围继续原映射，无积压 |
| 指令路径不允许 | PocketCamera.submit中rounded yaw与实际yaw差至少180°则拒绝；native队列也有既有路径检查 | 不越过原规则；单独标识pathUnreachable，暂停且保留校准。提示回到可达方向后明确恢复，不再强制重新对齐 |
| 底层队列/编码/所有权拒绝 | bool拒绝使App暂停，未证明整机断连 | 改为明确类型：transport、pose、path、stream、encoding、mailbox，不一律归为超限或断连 |
| 反馈持续偏离 | 原先比较controller已裁剪/过渡command，1秒异常会暂停 | 继续保留真实异常保护；精确比较成功提交并以0.1°编码的目标与新鲜实际回报，不拿raw目标比较 |
| 姿态失效、参考变化 | 原200/300ms、参考/时序判断使校准失效并停止 | 全部保留；不因正在限位而吞掉真实故障 |
| 真正传输中断 | 既有独立控制/视频证据与会话健康策略 | 全部保留；普通限位不调用disconnect、视频重建、清校准 |

没有源码证据显示第20包有“仅clamp就主动断连”分支，不能杜撰该根因。真实手机上若暂停，需按记录区分路径、反馈、输入或传输故障。本轮补齐准确分类、提示、目标核对及运行链路回归，不删除这些真实保护。

既有协议范围仍为yaw -48…225°、pitch -44…70°。这来自既有固定机身正式配置和固定上游定义，不代表本轮重新量过物理机械边界。默认roll不随头侧歪，绝对角度模式、目标流去积压、参数和频率均不改。

## 显示与交互

- 外观新增独立appearance偏好，默认跟随系统，浅/深覆盖保存；移除App与Info.plist强制深色。页面用systemBackground（白/黑）、分组用secondarySystemBackground、主/次文字用语义颜色。强调和警告采用适配浅深色的少量颜色。
- 视频UIView/AVSampleBufferDisplayLayer适配器逐字节保持原样，仍为resizeAspect。Surface按真实pictureAspect做fit；视频外背景随主题，视频不加滤镜、曝光、对比或裁切。玻璃仅用于紧凑栏与操作区域，低版本材质回退及减少透明度/动态效果保留。
- MonitorLayout固定三个子树：预览、紧凑状态栏、操作区。横屏独立预留侧区，左手设置改变侧区位置；竖屏操作在下。旋转只改布局，不换会话、decoder或方向参考；隐藏设备页下的监看不拦截触摸。
- 主界面显示简短当前原因、普通限位、录像实际/待确认状态及主要按钮。技术说明、历史操作、低频设备信息和诊断改为DisclosureGroup。
- 拍摄详情有180点/中/大三个原生detent，可点展开/收起，也可拖动；内容可滚动。详情打开、关闭、展开、滚动不调用控制动作。横屏详情导航栏保留显式暂停入口。跟随状态/诊断入口也不再因“查看”而暂停；实际设置修改、显式暂停/清校准等动作按原规则执行。
- 超限提示使用“目标已限位”，不声称镜头已到机械边界；回报未知/过期不宣称到位。数值只更新内容，原因使用稳定ID。普通限位标记出入不改变按钮或预览区域布局。

## 验证结果

本地72项核心测试通过，包括四边界、另一轴独立、持续超限、返回仍超限、归零、反复进出、平滑收敛、跨±180°、暂停及真实输入/连接故障。App与UI云端验证、编译提交和IPA指纹待完成后填写。

新增App回归验证真实AppModel/适配器的限位、反馈目标、录像独立、服务/decoder/校准保持与拒绝分类。新增UI回归用明确DEBUG受控输入，但真实呈现SwiftUI面板；CI宿主通过simctl实际切换系统外观，验证已打开面板响应，非伪造颜色环境。测试入口不在Release中。所有这些均不等于相机、AirPods或光学方向硬件验证。

## 最短真机验收

原Sideloadly账户覆盖，不卸载；更多→关于核对版本、构建号、分支和提交。保留第20包便于回退，系统侧签名与安装身份不变。

1. 设置外观跟随系统，在详情已打开时切系统浅/深；再手动浅/深并重启检查保存。查看浅深视频背景上的文字、减少透明度/动态效果和大字体。
2. 固定机身连接→校准→明确开始；独立录像。两侧横屏、左手布局、详情点击/拖拽及关闭，检查完整比例、所有主按钮、安全区和暂停入口。恢复/数据异常旧问题若复现仍按实际原因记录，不能归于限位。
3. 在既有真实可达范围内缓慢接近左右/上下边界，继续向外和开始回转但仍越界时应保持合法目标；进入范围后按原基准继续，回到校准方向返回原方向。单轴越界时另一轴只在实际可达条件下继续。重复数次，不应清校准、断连或影响录像。
4. 限位时手动暂停，再回到范围不应自行启动。真实姿态失效或断连仍应停止，必要时重新校准且明确开始。路径受限是另一原因，不应发送穿越不可达扇区的指令。

本轮未进行真实硬件验收，不能声称任何握持/机械边界、外部光学精度、移动机身补偿已通过。异常后从更多→本地诊断导出JSON，结合range_limited/range_clear、typed target_rejected、feedback、输入时效与连接事件定位；无需重复描述已经展示的现象。
